# Подготовка к личностям

Интерактивный сайт для подготовки по 22 историческим личностям.

## Возможности

- **Список** — все личности с портретами и поиском
- **Карточки** — повторение материала (показать / скрыть ответы)
- **Викторина** — по полному описанию выбираешь, кто это (4 варианта с фото)

Фотографии из исходного файла, встроены в HTML.

## Как открыть

Просто открой **index.html** в любом браузере — больше ничего не нужно.

## GitHub Pages

1. Создай репозиторий
2. Загрузи только `index.html` (и README.md по желанию)
3. Settings → Pages → Deploy from branch `main` → `/ (root)`
4. Сайт: `https://<username>.github.io/<repo>/`
